# Habit Pulse

**Timeline: 2 Months — Solo**

Habit Pulse is a full-stack SaaS habit-tracking platform. Instead of a bare-bones tracker, it's built as a production-ready product — with secure login, real-time reminders, analytics, and paid subscriptions — so users can actually stick with habits and pay for the pro tier.

## How it works

**1. OTP login** — Users sign in with Firebase-powered OTP auth instead of passwords, with automatic session management and an onboarding flow optimized for mobile.

**2. Habit tracking** — Users create, update, and track habits daily, weekly, or monthly, with visual analytics showing streaks and completion rates over time.

**3. Reminders** — Firebase Cloud Messaging sends real-time push reminders on a per-habit custom schedule, with retry queues and fallback handling so notifications actually land.

**4. Subscriptions** — Razorpay handles recurring billing: plan activation, renewals, and webhook-driven state updates, so subscription status stays accurate without manual checks.

## Highlights

- Built a **full-stack SaaS platform** with OTP auth, habit tracking, and analytics dashboards.
- Implemented **real-time push notifications** via Firebase Cloud Messaging with retry handling for reliable delivery.
- Integrated **Razorpay recurring subscriptions** with webhook-based billing state management.
- Optimized MongoDB with **compound indexes**, improving query performance by ~50%.

## Why it's interesting

The hard part wasn't the habit-tracking CRUD — it was making the SaaS layer reliable: notifications that actually deliver, subscriptions that stay in sync with billing events, and a database that stays fast as data grows. Habit Pulse ties all three together into one working product.
